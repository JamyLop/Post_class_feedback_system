# 一生一案通用模板（高三试点 · 一科一表）

> 基于 `docx/一生一案` 下 32 份历史材料（高三/初三/艺考）归纳，覆盖语文、数学、英语、物理、化学、生物、政治、历史、地理、德育 10 科，沉淀为可复用的“一人一案一科一表”底表。

## 文件
- `一生一案通用模板.docx`：可直接下发填写的 Word 表，版式与历史材料一致，含填表说明与数据映射。
- 本 `README.md`：模板结构、字段定义与系统/流程映射。

## 表结构（4 列 10 行，含表头）
| 核心板块 | 分项要点 | 具体要求与内容指南 | 备注 |
|---|---|---|---|
| **精准诊断与归因分析** | 学科问题定位（德育为“行为表现”） | 按学科逐条写差距，引用最近作业/考试证据；德育引用具体事例/时间。例：文学类主旨概括不准；文言18虚词记不全 | 必填，可引证据号 |
|  | 原因剖析（德育为“原因/背景”） | 与问题一一对应的深层成因：基础/方法/习惯/思维/复习节奏；德育加家庭/同伴背景 | 与问题对应 |
| **目标确立与强化方向** | 奋斗目标（德育为“养成目标”） | 可量化、分阶段：短期/中期/高考；德育如“两周作业按时率≥95%” | 确认后锁定 |
|  | 高考要求（德育为“规范要求”） | 对标考纲/校规：学业的“由表及里…”，德育的“按时到岗、笔记完整” | 对标 |
|  | 具体强化（德育为“日常优化”） | 可执行策略：四步法/六字诀/限时训练；德育的家校协同/谈话激励 | 可复盘 |
| **具体措施** | 任务清单 | 日/周/月任务：标题/内容/周期/起止；系统将生成执行记录 | 生成执行记录 |
|  | 具体时间安排 | 早读/自习/周末时间块与时长，与任务一一挂钩 | 与任务挂钩 |
| **督查与反馈** | 学生自查 | 课前/课中/课后三段自查 | 学生端 |
|  | 教师督查（班主任/学科） | 每周笔记、提问2—3题、作业/早读检测≥1次，记录问题/整改/截止 | 教师必填 |
|  | 校级/校长督察 | 每月查记录、协同整改、提出截止与复查结论 | 管理员 |

顶栏信息区：`姓名 / 班级 / 学科 / 班主任 / 备考周期 / 版本 / 填表日期 / 状态`，用于与系统 `StudentCase`（周期、班级、学生、负责人、状态、版本）对齐。

## 系统字段映射
| 模板单元格 | 后端模型/字段 |
|---|---|
| 学科问题定位/行为表现 | `SubjectPlan.problem_location` |
| 原因剖析/原因背景 | `SubjectPlan.cause_analysis` |
| 奋斗目标/养成目标 | `SubjectPlan.struggle_goal` |
| 高考要求/规范要求 | `SubjectPlan.gaokao_requirement` |
| 具体强化/日常优化 | `SubjectPlan.reinforcement` |
| 任务清单 | `CaseTask`（`title/description/cadence/starts_on/due_on/subject`） |
| 具体时间安排 | `CaseTask` 起止 + `TaskCheckin` |
| 学生/教师/校级/校长督查 | `CaseReview`（`review_level=subject/head_teacher/school/principal`） |
| 覆盖所有科目的总览 | `StudentCase.overall_problem / admission_target / current_summary` |

## 流转与权限
`草稿 → 待确认 → 执行中 → 待复盘 → 已调整 → 已归档`，进入`执行中`后总览与方案正文锁定，调整须走`发起复盘→确认已调整`并生成新版本（`CaseVersion`）；家长仅见已确认版本。任务与打卡在`执行中`持续录入，督查可随时追加。

## 填报规范
1. **一人一科一表**：综合材料中“语文：…；数学/物理：…”须拆分为单科独立记录，杜绝合并标签；已存在学科专属文档时以专属内容为准。
2. **原文完整性**：四列表格跨页保留重复表头，中文字体（建议嵌入“微软雅黑/思源黑体”）避免乱码，段落用编号+分行保持可扫读。
3. **证据锚定**：问题定位尽量标注题号/得分/日期（如“文言翻译题3-2 扣4分”），便于后续与作业/考试证据关联。
4. **德育单列**：新增`德育`作为独立学科，记录课堂/作业/纪律/品行，用“养成目标/规范要求/日常优化”三栏替代高考要求，保持同一底表。

## 复用方式
- 直接分发 `一生一案通用模板.docx` 填写，回收后按 `backend/app/services/document_import_service.py` 的 `extract_docx` 规则（`FIELD_MAP` + `SUBJECTS` 含德育）解析入库。
- 或在系统“学生档案 → 学科方案”中按模板字段在线录入，效果等价且自动落入版本链。

## 注意事项
- 历史5份首批材料已试导入但仍需逐人逐科人工核对，解析通过≠原文完全准确。
- 导入时文件名含学科关键字将自动判定 `detected_subject`，德育材料请在文件名或首段明确“德育”。
