# 学段主管与档案状态维护

- 用户管理增加“初中主管”“高中主管”页签，从在用任课老师中添加或移除主管身份。每个老师可担任一个学段的主管，保留原任课关系。
- 主管工作台提供月度评定填写状态与月考总览。范围取自 `Class.education_stage`，在分页、汇总和排名前过滤；班级年级名称不参与推断授权。
- 主管查询使用 `scope=supervision`，只读；普通任课页面继续使用 `scope=teaching`。撤销身份后旧登录凭证立即失去主管查询权。主管身份不授予档案维护、代填、发布或改分权限。
- 小程序的管理员档案详情增加校级督查入口，表单可选择校级／校长督查；指定档案直接读取详情，避免列表分页遗漏。
- Web 和小程序的管理员档案详情提供“调整档案状态”。原因必填，服务端校验当前状态以拦截过期请求；写入操作人、原状态、目标状态与操作前快照。
- 状态维护不修改教学阶段版本或任务归属；旧待审事项关闭。调整为待整改时建立校级整改事项，班主任可整改、重新送德育审核。
