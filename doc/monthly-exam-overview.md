# 月考成绩总览

Web 和小程序共用 `GET /api/monthly-exam-scores/overview`，继续使用已有月考录入数据，无需新增表或数据库迁移。旧成绩录入和教师评价保留在“单科明细与评价”中。

## 可见范围

| 身份 / 实际班级关系 | 可见成绩 |
| --- | --- |
| 管理员、德育主任 | 全校各班各科、总分和排名 |
| 班主任（原班主任字段或 head_teacher 关系） | 所带班级各科、总分和排名 |
| 任课老师（含班主任在其他班兼课） | 关联班级对应科目和科目排名，不返回总分 |

后端先按班主任及任课关系限制数据，再计算统计。学生、家长、咨询老师不能读取此成绩册接口，其原有个人/关联学生成绩入口不变。

## 排名规则

- 默认查询当前账号有权查看的最新考试月份，也支持明确指定月份；考试日期跨月不改变成绩归属月份。
- 同分使用竞赛排名，例如 1、1、3。班级、姓名筛选和分页均不重新计算排名基数。
- 班内排名只比较同班、同科目及满分的成绩。可见范围排名只比较账号可见的同年级、同科目及满分的成绩；管理员和德育主任包含全校，老师仅包含所带范围。
- 学生学习科目取同班本人最新未归档档案的入学评定学科方案，排除德育。同班学生可以有不同选科，表格对本人未选科目显示“—”。
- 总分仅汇总本人已录入的初评科目成绩；初评之外的历史成绩保留在原记录，不参与成绩总览和排名。零分为有效成绩。
- 本人初评科目成绩全部录入后，才按选科及各科满分配置相同的学生计算总分排名。页面不再显示“未齐”提示。
- 尚未建立初评时不套用全班科目，总分与排名显示“—”。
- 完全未录入成绩的学生不进入成绩册，页面人数明确标注为“已录入学生”。

## 查询和验证

支持 `exam_month`、`class_id`、`grade`、`subject`、`keyword`、`limit`、`offset`。`subject` 指定按对应科目降序排列，仍返回有权查看的其他科目。未指定科目时，有完整总分者按总分降序排列。

聚合在分页前覆盖全部当月可见记录，不依赖旧列表默认的 200 条限制。月份为空的迁移前历史记录不参与统计。

在 backend 目录运行：

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_monthly_exam_overview.py tests/test_monthly_exam_scores.py tests/test_weekly_scores.py -o addopts= -q
```

页面模拟数据验证脚本及截图位于 `output/monthly-exam-overview-20261020/`。实际小程序仍需在微信开发者工具或真机验收。
